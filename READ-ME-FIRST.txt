MRI TAG + MOBILE IMAGE LIBRARY
==============================

The database change is already applied to the live project. Nothing to run.
This zip is the code side only.

HOW TO UPLOAD (GitHub web)
--------------------------
1. Open https://github.com/UofTNeuromuscularFellowship/Fellowship
2. Add file -> Upload files
3. Extract this zip, then DRAG THESE THREE FOLDERS onto the page:

       src
       public
       supabase

   DO NOT drag the folder that contains them, and do not drag
   READ-ME-FIRST.txt. GitHub keeps the folder structure, so dragging "src"
   puts the files back exactly where they belong.

4. Commit. Vercel redeploys on its own.
