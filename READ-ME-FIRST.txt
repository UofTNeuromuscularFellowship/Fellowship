FULL-SCREEN VIEWER + EDIT DESCRIPTION
=====================================

Three files. No database change.

1. Open https://github.com/UofTNeuromuscularFellowship/Fellowship
2. Add file -> Upload files
3. Extract this zip and DRAG THE "src" FOLDER onto the page.
   Do not drag the folder that contains it, and do not drag this readme.
4. Commit. Vercel redeploys on its own.

WHAT YOU GET
------------
1. An expand button in the top-right corner of every image, including the
   frame captured from a clip. It opens the image full screen with its
   annotations, its legend and its description.
   - "Actual size" shows a wide trace at full width so you can scroll along it
     instead of squinting at a fitted-to-screen version.
   - Escape, the X, or a tap outside the image closes it. Tapping the image
     itself does not, so a missed tap will not throw you out.

2. "Edit details" on any case you can edit — change the title and the
   description after upload.

WHAT IS DELIBERATELY NOT EDITABLE
---------------------------------
The media kind, the file itself, and the signed consent. Changing the kind
would strip findings tagged against the old kind, and could move a case in or
out of needing consent — and a case whose kind or media changed would no
longer match the consent recorded against it. To change those, delete and
re-upload. Tell me if you would rather it worked differently.
