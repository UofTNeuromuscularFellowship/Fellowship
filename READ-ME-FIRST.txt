Everything outstanding, merged into one consistent set. It supersedes
"fellowship-atlas-files.zip", "restore-library-nav.zip" and

HOW TO UPLOAD

Unzip it. Open the folder you get. Drag the src, supabase and tools folders
THAT ARE INSIDE IT into the GitHub uploader at the ROOT of the Fellowship repo
(Add file -> Upload files).

  DO drag:   src   supabase   tools
  DO NOT drag the folder that contains them.

.gitignore sits at the top level too. Optional — it stops node_modules and
build output showing as untracked.

WHAT IS IN IT

1. Multiple approaches per muscle (new)
   - A row of approach chips under the summary bar, visible to everyone.
     Triceps shows Long Head / Medial Head / Standard; choosing one swaps the
     marker on the model and the note beside it.
   - Only approaches that actually carry a marker the reader may see are
     listed, so a fellow never gets a chip that shows an empty model.
   - EMG now shows each approach's authored label and note, as nerve
     conduction already did. That text is what separates one approach from
     another.

2. "Centre" button (new)
   - Slides the view so the highlighted muscle sits in the middle of the
     canvas, keeping your current angle and zoom. Next to "Reset view", which
     returns to the region's default framing.

3. Library
   - Read / Download / Remove keep their own right-hand column and never wrap
     under the title. File name out of the subtitle; size moved beside the
     buttons.

4. Supervisors can publish their own atlas markers
   - Approve, edit and remove markers they placed — not anyone else's.
   - Fixes a Delete button that looked like it worked but did nothing.

5. Library and Feedback review restored to the nav
   - Undoes what my earlier atlas upload removed.

6. The 3D atlas work from the last few days
   - NCS highlights the study's recording muscle instead of click-to-select;
     study search and grouping by nerve; panning; cathode degree readout and
     the cathode-to-G1 distance feature both removed.

ONE THING TO FIX YOURSELF

The triceps lateral-head approach is still named "Standard" in the database,
so the chips read "Long Head / Medial Head / Standard" even though that third
marker's own label says "Lateral Head". Rename the approach to "Lateral Head"
in the authoring panel and the three chips will read correctly. I did not
rename it myself — it is your authored clinical content.
