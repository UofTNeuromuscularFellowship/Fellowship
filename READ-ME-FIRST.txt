UPLOAD THIS ONE — IT REPLACES THE EARLIER ZIPS
==============================================

This is everything outstanding, merged into one consistent set. It supersedes
"fellowship-atlas-files.zip" and "restore-library-nav.zip". Upload this and
ignore those two — mixing them would undo work, because they each contain
different versions of the same files.

HOW TO UPLOAD

Unzip it. Open the folder you get. Drag the src, supabase and tools folders
THAT ARE INSIDE IT into the GitHub uploader at the ROOT of the Fellowship repo
(Add file -> Upload files).

  DO drag:   src   supabase   tools
  DO NOT drag the folder that contains them.

Dragging the outer folder is what created the stray "atlasncsupdate" folder
last time and left the real files untouched.

.gitignore is also in here, at the top level. Optional — it just stops
node_modules and build output showing as untracked. Drag it in alongside the
folders if you want it.

WHAT IS IN IT

     remain; the file size moved over beside the buttons.

2. Supervisors can publish their own atlas markers
   - A supervisor can now approve, edit and remove the needle and NCS markers
     they placed. Not anyone else's — the database checks authorship.
   - Fixes a Delete button that looked like it worked but silently did nothing
     for supervisors.

3. Library and Feedback review back in the nav
   - Restores the routes and nav items my earlier atlas upload removed.

4. The 3D atlas changes from the last few days
   - NCS mode highlights the study's recording muscle instead of letting you
     click-select; study search and grouping by nerve; panning; cathode degree
     readout and the cathode-to-G1 distance feature both removed.
