HOME OPENS THE DASHBOARD DIRECTLY
=================================

Three files. No database change.

1. Open https://github.com/UofTNeuromuscularFellowship/Fellowship
2. Add file -> Upload files
3. Extract this zip and DRAG THE "src" FOLDER onto the page.
   Do not drag the folder that contains it, and do not drag this readme.
4. Commit.

WHAT CHANGES
------------
- Home now opens the dashboard directly. No overview page in between.
- Clinic does the same, opening the clinic schedule directly. It had exactly
  the same problem — an overview listing one card — and it would have been odd
  to fix one and not the other. Say the word if you would rather it kept its
  overview.
- Those two areas also lose the "Overview" line in the side panel, since it
  would point at a page describing the only other link there.
- Areas with more than one tool are unchanged: Teaching, Case Log, EMG Toolkit,
  Program and Settings all still open their overview.

This is automatic, not a list I maintain: any area holding a single tool opens
that tool, and starts showing an overview by itself the moment a second tool is
added to it.
